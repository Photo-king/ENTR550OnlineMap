## 地图生成与 Ground 几何

- 原始 SVG/PNG 保留在 `Mapsv1.0/`，生成过程不覆盖它们。三层单层图于 2026-11-19 更新为用户提供的 Team 2D corridor draft，统一使用原有楼层文件名；Overview 沿用原图。
- `scripts/prepare-maps.py` 生成交互地图、图例、说明及足迹数据，源文件与生成结果都要一起提交。
- 三层使用矩形窗口裁掉版式区，保留源图墙线，不以手工足迹剪掉墙线或另画外墙。First 的北入口文字额外保留，显示范围向南北扩展以容纳两侧入口标注。
- 新 SVG 已将原平移和缩放展开为绝对坐标，仍使用 `0 0 2280 1650` 参考系，现有定位控制点和楼层配准不变。脚本保留内部蒙版及嵌入图标。
- 2026-11-21 Ground 更新为 `Dental_Kellogg_Ground_2D_Drive.svg`（原文件 `2200 × 2100`）。脚本先移除外层打印变换 `matrix(1.5 0 0 1.5 -900 -270)`，再对建筑内容应用内部变换 `new = old × 1.08 + (-204, -69.6)` 的逆变换，恢复原坐标。四个原参照墙角与恢复后的源图墙线顶点偏差均小于 0.004 SVG 单位，保留全部源图墙线及原有黑色房间文字，去除四处覆盖其上的重复蓝色标签文字。
- 三层的室外页面底板透明，室内填充保留白色，画布统一为浅绿色。脚本中的足迹填充不改墙线。
- 所有楼层清理大块标签底色，保留一份房间文字；Second 的 Pediatrics、Oral Surgery、Grad Restorative 保留原黑色文字，去除覆盖其上的蓝色重复文字，Patient Check-in 则保留新增文字。
- 三层固定符号/颜色图例使用 First 版本，各层目的地和展览说明单独保留。

## 当前交互与验证

Overview 是原始三层总览示意图，作为默认主页；支持查看时的双指缩放与拖动，但不显示地理定位点。G/1/2 显示蓝色定位点，灰色表示最后已知位置。全部页面初始及最小缩放完整适配设备；变换只影响地图，不改变图例面板尺寸。

位置不以是否落在建筑足迹内作为显示门槛；有效坐标始终映射，超出视口自然裁切。楼层由用户选定。公开页面自动请求权限，隐藏坐标、误差及测试入口。需要核对数据时仅在本地显式开启 `ENABLE_LOCATION_DEBUG`，不可把调试开关打开的版本发布给组员。
